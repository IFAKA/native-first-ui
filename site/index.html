Built from good ideas

Small by default, capable when installed

Native-First UI combines the strongest lessons from projects that shaped the web’s practical UI layer. It is not a replacement for each one at its specialty; it brings their complementary strengths into one native-first workflow.

Lit + Min

Byte discipline and a deliberately small surface area.

New.css + Milligram

Classless semantic defaults plus practical controls and forms.

Pure.css + shadcn/ui

Modular CSS and local, editable recipe ownership.

Vercel Guidelines + Emil Kowalski

Clear states, accessible interactions, and restrained purposeful motion.
